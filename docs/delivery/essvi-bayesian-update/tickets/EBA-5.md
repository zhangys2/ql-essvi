## What to build

Complete the held-out replay reporting removed from EBA-4 to retain the five-file gate. Compare each successful current warm and cold surface against the prior surface carried into the warm update on exact matched expiries, using the deterministic 101-point log-moneyness grid from -0.5 to 0.5 and RMS total-variance movement. Report per-update and daily movement counts/metrics in the existing benchmark JSON/text and replay JSON/CSV outputs. Count both `fallback` and `degraded` warm paths as fallback updates in the daily fallback rate. Declare the held-out replay command and limitations in `docs/delivery/DELIVERY.md`.

## Acceptance criteria

- The benchmark independently reports warm and cold movement update counts and per-update RMS total-variance movement over exact matched expiries and the fixed 101-point grid. Unmatched expiries are excluded; a failed or unmatched path does not suppress movement from the other successful comparable path, and no comparable movement is represented as unavailable/null rather than zero.
- Daily replay aggregation reports independent warm/cold movement update counts, mean per-update RMS using each path's own update count, and summed matched-expiry/grid-point counts in JSON and CSV. Aggregation weights each path's updates equally, matching the benchmark's per-update statistic.
- Daily fallback updates and rate include both `fallback` and `degraded` path counts, use all warm replay samples as the denominator, and return unavailable/null when there are no samples.
- Regression coverage checks benchmark JSON/text movement summaries in both fit-failure directions, partial expiry overlap, no comparable movement, and an independent formula reference; daily tests distinguish per-path aggregation, missing movement, degraded-path fallback counting, zero-sample behavior, and one-sided JSON/CSV unavailable values.
- `docs/delivery/DELIVERY.md` declares the runnable held-out replay command, data-root requirement, movement definition, and limitations. Report actual replay results without unsupported predictive or performance claims; retain the European Black--Scholes IV stand-in caveat for American options.
- Existing calibration behavior, quote-quality gates, and non-replay output contracts remain unchanged.
